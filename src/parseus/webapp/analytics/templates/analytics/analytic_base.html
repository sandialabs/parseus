Welcome
The links below are designed to facilitate the training and prediction of various analytical models organized into columns.

1. Available Analytics: Lists models with info buttons for details. Users can configure fields and click Train to initiate training on data from the Malcolm database. (Not used in unsupervised section)

2. Trained Analytics: Displays previously trained models. Users can click Predict to make predictions on new data using the selected model.

3. Results Display: Shows prediction results as JSON objects
  • Peat Supervised Analytics
    Run analytics on Peat pull results that require baseline/training data.
  • Peat Unsupervised Analytics
    Run analytics on Peat pull results that do not require baseline/training data.
  • Network Supervised Analytics
    Run analytics on network data in Malcolm database that require baseline/training data.
    • Network Anomalies: Identifies odd traffic patterns in documents ingested by Malcolm.
    • OT Network: Identifies unusual operational technology function codes in network traffic provided from Zeek/Malcolm parsers.
    • SCPI: Used regularly in lab equipment. Will require ingestor provided by the GPIB integration.
  • Network Unsupervised Analytics
    Run analytics on network data in Malcolm database that do not require baseline/training data.
    • Host Anomalies: Identifies odd traffic patterns in host patterns ingested by the Winlog/Logstash integration.
