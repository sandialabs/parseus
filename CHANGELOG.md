## [1.0.0] - 2026-10-31

Initial public release.

### Added

- Web application for retrieving, analyzing, and visualizing operational technology (OT) security data, backed by an Elasticsearch or OpenSearch datastore.
- **Analytics** app for running supervised and unsupervised analytics against datasets in the datastore, training models from known-good data, and reusing trained models for later runs. Analytics can run on a schedule through Celery.
- 17 built-in analytics, grouped by family:
  - Network anomalies: excessive conversations, new communications, port-scan targets.
  - Host anomalies: unapproved Sysmon devices, users, and IP addresses.
  - OT network: OT protocol (DNP3, Modbus) function-code anomalies.
  - OT internals (PEAT): authentication enumeration and changes to device, firmware, logic, file, I/O, process, and service data.
  - SCPI: command comparison and value-range checks.
- **Alerts** app for tracking, triaging, and resolving alerts generated by Sysmon and SCPI analytics.
- **OT Registers** app for retrieving Modbus register values, visualizing them as line graphs, and analyzing function codes, including HDBSCAN clustering and PCA.
- **PEAT** app for interrogating OT devices (pulling and parsing configuration, firmware, and process logic, plus network scanning), installed with the optional `parseus[pei]` extra.
- Plugin architecture: feature apps and analytics are discovered through the `parseus.apps` and `parseus.analytics` entry-point groups, so external packages can add their own.
- `manage_parseus.py` / `manage-parseus` management tool (Python 3.8+, standard library only) with `install`, `upgrade`, `up`, `down`, `restart`, `status`, `uninstall`, and configuration helper commands.
  - Repository-based and offline bundle-based installation (`make package` produces `dist/parseus-<version>.tar.gz`).
  - HTTPS with generated self-signed or user-provided certificates.
  - Optional systemd unit so the stack starts on boot.
  - Installation manifest that records the installed application version.
- Optional ingestion integrations, enabled with `--integrations`:
  - `gpib`: GPIB-over-Ethernet payload ingestion.
  - `winlog`: Windows event (Winlogbeat-compatible NDJSON) ingestion through Logstash, with 90-day index retention.
- Documentation: [management](docs/MANAGEMENT.md), [development](docs/DEVELOPMENT.md), and [troubleshooting](docs/TROUBLESHOOTING.md) guides, plus integration guides under `deploy/integrations/`.

### Notes

- Deployment supports Linux (x86_64 / AMD64) only. It requires Docker, Docker Compose v2, and OpenSSL.
- The application source requires Python 3.11 - 3.13.
